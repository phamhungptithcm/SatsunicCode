EasyArrays & Hashing

Contains Duplicate

A batch contains integer event codes. Return true if any code appears more than once; otherwise return false.

Examples

Input [42, 7, 42, 19] Output true
Input [-8, 0, 13, 27] Output false
Input [] Output false

Constraints

0 ≤ batch size ≤ 100,000
Signed 32-bit integers. Preserve the input.
